### R8-1 · 正确性收口（D 线）

| 项 | 内容 |
|---|---|
| 目标 | ①过期 checkpoint 不返回旧值 ②billing 跨进程读得到真数据 ③RLS 用非 superuser 实证 ④回测产物不再硬编码合成价 |

| 禁止 | 其他 src 文件、tests/ 其他文件、docker-compose.yml、migrations/ |

```text
你在 /root/projects/hero-quant 执行 R8-1：正确性收口。只碰 checkpoint/postgres.py、billing/service.py、api/server.py（仅回测产物段）、tests/test_checkpoint_pg.py，可新建 tests/test_billing_rls_real.py。
python 用 .venv/bin/python。

环境：PG = llm-pg @ 100.114.54.26:5432，库 heroquant 已建，超级用户在容器内 $POSTGRES_USER。Redis = llm-redis @ 100.114.54.26:6379。127.0.0.1 不通。磁盘 1.8G，禁止重复 build。

【1】checkpoint 过期后返回旧值（正确性 bug，最高优先）
 - 现象：checkpoint/postgres.py 的 get()/get_with_config() 在 PG 行因 expires_at 过期被 SQL 过滤返回 None 后，继续回退到 emulated 缓存（_PG_GLOBAL，约 :104）并返回旧值。
 - 该问题被 tests/test_checkpoint_pg.py:56 的 @pytest.mark.xfail(strict=True) 锁住，等于承认但未修。
 - 要求：只要有真实 PG 池，读取就以 PG 结果为唯一真值；PG 返回 None（无论不存在还是已过期）都直接返回 None，不得回退 emulated。emulated 缓存只允许在"无池"路径使用。
 - 同步：①去掉该 xfail marker，确保修复后真绿；②补一条用例：写入 → 把 expires_at 推到过去 → get() 返回 None（不能返回旧 payload）。
 - 验收：.venv/bin/python -m pytest tests/test_checkpoint_pg.py -q 全绿且无 xfail。

【2】billing 跨进程读因子是桩
 - 现状：_get_global_factors（约 :399）/ list_factors（约 :812）/ get_factor（约 :838）在 PG 模式下仍读进程内 dict，另一进程 publish 的因子读不到。
 - 要求：_is_real_pg() 为真时，list_factors / get_factor 走 PG 查询（tenant 过滤、created_at 倒序、limit 有界）；无池时保持现状但返回体带 degraded。禁止 PG 模式下返回内存数据冒充。
 - 验收：进程 A publish → 独立进程 B list_factors 能读到；无 DSN 时返回 degraded 而非假成功。

【3】RLS 实证（已获授权）
 - llm-pg 的超级用户绕过 RLS，现有测试证明不了隔离。允许在 llm-pg 上 CREATE ROLE heroquant_app LOGIN PASSWORD <从环境变量取> NOSUPERUSER，并 GRANT 必要的 CONNECT/USAGE/SELECT/INSERT/UPDATE 到 heroquant 库的 billing 表。
 - 新建 tests/test_billing_rls_real.py：用该角色连接，验证 set_config('app.tenant','t1',true) 只能看到 t1 行；切 t2 看不到 t1；未设 tenant 时 0 行（fail-closed）。
 - 用环境变量门控（如 HERO_RLS_TEST_DSN），未配置则 skip 并打印原因，不得让默认 CI 变红。
 - 验收：配置 DSN 跑该文件全绿；不配时 skip=1 且有原因。

【4】回测产物不再硬编码合成价
 - server.py 的 _compute_backtest_bundle（约 :2420-2430）现在用 base = 1680.0 造 20 日行情，只加了 degraded 标记。
 - 要求：优先用真实数据（tools/market_data.py 的 get_market_data，allow_synthetic=False）；拿不到就返回空 metrics + degraded + reason，不要再造合成 K 线。若保留 demo，必须由显式开关（如 HERO_BACKTEST_DEMO=1）开启，默认关闭。
 - 验收：默认请求 /v1/backtest/metrics.json → 真数据或空 + degraded；响应不出现 1680.0 系数字。

约束：不改 loop 控制逻辑；不动 tools/ 与 data/；不 push；显式 git add；前缀 D:。
结束按 docs/plan-2026-10-28-p0-fix.md §3.4 模板回报。
```
