## 5. 已知坑（省时间）

- 两个 pytest 并发会抢本地 dev Redis 限流桶 → fuzz 假 429；必须串行。
- worktree 没有 `frontend/dist` 会让 `test_frontend_spa` 多 1 skip；没有 `node_modules` 时用 `cp -al`（软链会进 git status）。
- 新 e2e spec 必须在 `playwright.config.ts` 注册 project，否则 `--list` 都是 0。
- `_final_answer` 的调用点是 `asyncio.to_thread(_final_answer, ...)`，`grep "_final_answer("` 只命中定义，别误判"零调用"。
- PG 测试族：`conftest.resolve_pg_dsn` 首次解析后冻结；改 DSN env 必须用 monkeypatch，裸 `os.environ.pop` 会污染后续用例。
- 真实评测：网关不回 usage → `estimated=true`、cost=null；报告时必须带这个限定。
