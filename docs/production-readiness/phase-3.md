# Phase 3 · 运营与可选升级

> 前置：G2 通过。目标：从“团队可用”到“可持续运营”：单机可靠性、容量、成本、隐私、运营闭环；HA 仅在业务需要时升级。
> 验收门：`README.md` §4 的 **G3**。

---

## 1. W7 单机可靠性与灾备

### 1.1 单机加固（PR-301）

- 独立数据盘（PG/Redis/产物/备份分离）；文件系统监控与告警；UPS/断电保护（如物理机）。
- 资源 limits + 容器重启策略 + 磁盘配额；日志轮转；内核/安全补丁窗口。
- 健康检查：`/live` 仅进程存活，`/ready` 检查 PG/Redis/依赖；失败摘流不重启。
- 关键数据每日备份 + WAL 归档；每月恢复演练。
- **验收**：磁盘/内存/进程故障演练有记录；备份可恢复；RTO/RPO 达标。

### 1.2 压测与容量（PR-302）

- k6/Locust 场景：问答并发、SSE 长连接、回测批量、Billing 列表。
- 观测 p95/p99、错误率、PG 连接数、Redis 命中、LLM 速率限制。
- 产出单机容量基线（QPS/并发会话数/回测吞吐）与扩容阈值。
- **验收**：压测报告；达到目标并发无雪崩；限流/排队生效。

### 1.3 故障演练（PR-303）

- 注入：PG 重启/磁盘满、Redis 不可用、LLM 超时/429、worker 崩溃、证书过期。
- 验证：降级标记、熔断、重试、队列不丢、告警触发、恢复步骤可执行。
- **验收**：每类故障有演练记录与修复项；无静默失败。

### 1.4 可选升级：双机/托管/K8s（PR-304）

- 仅当单机容量或可用性不满足时启用；方案：冷备机 + 定期恢复、主备数据库、或迁移托管平台/K8s。
- 定义切换/回切流程、数据复制、DNS/反代切换。
- **验收**：升级演练一次；RTO/RPO 达标。

**任务**：PR-301、PR-302、PR-303、PR-304。

## 2. W5 成本、SLO 与运营指标

### 2.1 租户成本与配额（PR-311）

- 每租户日/月 token 与金额预算；80% 告警、100% 降级（quick 模型/拒绝）。
- 成本看板按租户/模型/任务类型；账单导出（内部结算）。
- **验收**：超预算行为可复现；账单与 usage 对账一致。

### 2.2 模型路由与优化（PR-312）

- 按任务类型/租户路由 deep/quick；缓存（相同 query/prompt 版本）；批量 embedding。
- 指标：缓存命中率、平均成本/任务、节省金额。
- **验收**：成本下降有对照；质量不退化（eval）。

### 2.3 SLO 报告与错误预算（PR-313）

- 月度 SLO 报告：可用性、延迟、成功率、成本；错误预算消耗与冻结策略。
- **验收**：报告自动生成；超预算触发发布冻结。

**任务**：PR-311、PR-312、PR-313。

## 3. W6 隐私与合规

### 3.1 数据保留/删除/加密（PR-321）

- 分类：会话、trace、审计、计费、对象存储产物；各自保留期。
- 用户删除请求：级联删除/匿名化；审计保留但去标识。
- 加密：传输 TLS、静态加密（PG/对象存储）、密钥轮换。
- **验收**：删除请求可验证；备份中的过期数据按策略清理；加密检查通过。

### 3.2 数据授权与采购（PR-322）

- 盘点 akshare/tushare/yahoo 的许可范围；内部研究 vs 对外分发边界。
- 如需对外，采购合规行情/基本面源；合同与再分发限制入文档。
- **验收**：数据源清单含许可/限制/责任人；对外功能前完成采购。

### 3.3 红队与复测（PR-323）

- 每年至少一次红队/渗透复测；覆盖新增端点与工具；P0/P1 闭环。
- **验收**：报告与修复记录；无未接受的高危项。

**任务**：PR-321、PR-322、PR-323。

## 4. W9 运营与反馈闭环

### 4.1 运营后台（PR-331）

- 用户/租户/配额/审计/kill switch/模型开关；操作二次确认与审批。
- 指标：活跃用户、任务量、失败原因 TopN、成本。
- **验收**：admin 可完成日常运维；操作全审计。

### 4.2 反馈与评测闭环（PR-332）

- 用户反馈（点赞/点踩/备注）→ badcase 池 → 标注 → 进 golden set → 回归。
- 每月评测报告：质量/成本/延迟趋势；驱动 prompt/模型/工具改进。
- **验收**：反馈到回归的闭环跑通；报告可查。

**任务**：PR-331、PR-332。

---

## 5. W10 发布工程

### 5.1 Feature flags 与灰度（PR-341）

- 开关：新模型/新工具/新页面/租户白名单；按租户/比例灰度；一键回滚。
- **验收**：灰度发布可回滚；开关变更审计。

### 5.2 发布列车与版本策略（PR-342）

- 固定发布节奏；版本语义化；breaking change 提前公告；弃用策略；CHANGELOG 自动生成。
- **验收**：发布清单/回滚演练；版本与镜像 tag 一致。

**任务**：PR-341、PR-342。

## 6. G3 验收清单

- [ ] 单机磁盘/内存/进程故障演练通过；备份恢复 RTO/RPO 达标。
- [ ] 压测达到目标并发；限流/排队/资源限制有效。
- [ ] 故障演练覆盖 PG/Redis/LLM/worker/证书，无静默失败。
- [ ] 租户成本/配额/账单可用；超预算降级。
- [ ] 数据删除/保留/加密合规；数据源许可清单完成。
- [ ] 红队/渗透复测无未接受高危。
- [ ] 运营后台与反馈闭环可用。
- [ ] feature flag/蓝绿/回滚/发布列车落地。
- [ ] （可选）需要 HA 时，双机/托管/K8s 升级演练通过。
